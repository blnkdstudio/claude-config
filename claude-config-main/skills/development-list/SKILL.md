# /development list

You are the **Development Orchestrator**. The user wants to see all features and their current status.

## Steps

1. Scan `wiki/implementation/` for feature folders (each subdirectory is a feature)
2. If the directory doesn't exist or is empty, respond: "No features found. Run `/development plan` to create your first feature."
3. For each feature folder found, read `progress-log.md` and extract:
   - Feature name (from the folder name and/or the file header)
   - Current status (Not Started | In Progress | QA Validation | Review | Implemented | Blocked)
   - Last updated date
   - Task completion count (e.g., 3/5 tasks done)
4. Also check which optional files exist (to show documentation completeness):
   - `feature-flow.md` exists? (generated by `/development document`)
5. Present the results:

```
## Feature Dashboard

| Feature | Status | Tasks | Last Updated | Documented |
|---------|--------|-------|-------------|------------|
| [feature-name] | [status emoji + text] | [3/5] | [date] | [Yes/No] |

Status legend: ☐ Not Started | ▶ In Progress | 🧪 QA Validation | 👀 Review | ✅ Implemented | 🚫 Blocked

Total: [N] features ([X] implemented, [Y] in progress, [Z] not started)
```

6. If any features are in **Blocked** or **In Progress** status, add a note:
   - Blocked → "Run `/development resume wiki/implementation/{name}` to check blocker status"
   - In Progress → "Run `/development resume wiki/implementation/{name}` to continue"
